# Estructura del informe ChronoSleep / Full report structure / Estrutura do relatório

1. **Resumen / Summary / Resumo**
   - Social jetlag actual
   - Social jetlag del plan
   - Una frase de interpretación no clínica

2. **Tu semana / Your week / Sua semana**
   - Tabla Día 1–7: tipo, hora de acostarse, hora de despertar, duración
   - Gráfico comparativo actual vs plan

3. **Escenarios / Scenarios / Cenários**
   - Sin flexibilidad laboral
   - Flexibilidad declarada
   - Siguiente escalón de flexibilidad, si existe

4. **Sensibilidad / Sensitivity / Sensibilidade**
   - Rango por incertidumbre de autorreporte
   - Aclaración: no es intervalo de confianza

5. **Contexto poblacional / Population context / Contexto populacional**
   - Referencia NHANES EE. UU. 2017–2020
   - No usar como diagnóstico ni percentil clínico

6. **Cómo se calculó / Method / Como foi calculado**
   - Fórmulas resumidas
   - Supuestos
   - Fuentes y versión del motor

7. **Límites y seguridad / Limits & safety / Limites e segurança**
   - Casos fuera de alcance
   - Cuándo revisar inputs
   - Cuándo considerar orientación profesional
